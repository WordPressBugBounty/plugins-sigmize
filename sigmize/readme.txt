== Description ==

**Stop guessing on your website. A/B test like the top 1% of sellers.**

Sigmize is the only WordPress plugin that combines A/B testing, element testing, heatmaps, session replays, custom goals, and real revenue tracking for WooCommerce, SureCart, and EDD stores. See which variations actually increase sales, not just clicks. All built directly into WordPress. Turn more visitors into customers without leaving your dashboard.

Built specifically for WordPress stores using WooCommerce, SureCart, or Easy Digital Downloads.

**Why Your Website Isn't Converting (And How to Fix It)**

Most WordPress site owners rely on gut feelings to design their sites. They change headlines, test colors, adjust CTAs, but they never actually know what moves the needle. The result? Hundreds or thousands in wasted potential revenue every month.

**Sigmize** changes this. By combining powerful A/B testing with behavioral analytics and revenue tracking, you'll finally understand exactly what your visitors want and how they interact with your site.

**Key Features:**

**1. Unlimited A/B & Element Testing (No Code)**

Create unlimited A/B tests without coding. Test:

* Entire page layouts
* Individual elements (headlines, buttons, sections, forms, images)
* Product images, pricing, and copy
* Checkout flows and upsell layouts

Element testing lets you change just one or a few elements on your page and run an A/B test comparing the modified version against the original. See precisely how those small changes impact conversions and revenue.

Sigmize's anti-flicker technology means your visitors see smooth variations without jarring content shifts that hurt user experience.

**2. Session Replays: See Real User Behavior & Fix Friction**

Session replays show you exactly how real users navigate your site. Watch recordings to see:

* Where users hesitate or rage-click
* Which sections confuse them
* Where they drop off in your funnel or checkout

Fix these friction points before they cost you sales and churn.

**3. Heatmaps & Scroll Maps: Visualize Engagement**

Heatmaps reveal where users click, hover, and engage. Scroll maps show exactly how far down the page visitors go, so you know:

* Which sections are seen vs ignored
* Where CTAs should be placed
* Which content blocks users never reach

Stop wondering what works and start seeing it.

**4. Custom Goals That Match Your Business**

Go beyond simple "page view" metrics. Sigmize lets you define and track custom goals that matter to your store:

* Track how far users scroll on the page (scroll-depth goals)
* Track how long users stay on the page (time-on-page / engagement goals)
* Track form submissions, including SureForms and other custom forms on A and B variants
* Track affiliate link clicks, button clicks, signups, and other custom events

Custom goals give you clear insight into engagement and micro-conversions, not just final purchases.

**5. WooCommerce, SureCart & EDD Revenue Tracking**

For WooCommerce, SureCart, and Easy Digital Downloads stores, Sigmize connects your sales directly to your tests:

* See revenue per variation
* Track add-to-cart, purchase completion, and conversion rate per variant
* Measure average order value (AOV) per variation
* Monitor cart abandonment impact when testing checkout flows

You'll know exactly which variation increased sales, not just which one got more clicks.

**6. CMP Integration & GDPR Compliance**

Sigmize is built to be privacy-conscious and GDPR compliant.

* Use Sigmize's own consent banner (CMP) to manage tracking consent
* Or integrate easily with third-party CMPs like CookieBot
* If you're already using CookieBot, you can connect it to Sigmize with a simple configuration so your tests, heatmaps, and replays respect user consent

This makes it easy to stay compliant while still running experiments and collecting behavioral data.

### External Service Connection / Security
Sigmize connects your WordPress site with our SaaS securely. When a user initiates a connection, they are redirected to the SaaS login page. Upon clicking Connect, the SaaS generates a short-lived, single-use token which is sent back to WordPress via a redirect. WordPress then verifies the token server-to-server before storing the access token and user data for future API calls. Tokens are time-limited (1–5 minutes), single-use, and encrypted in transit using HTTPS. This ensures secure authentication, prevents token reuse, and protects user data. No actions are taken by WordPress until token verification succeeds. The access token will be used to sync A/B test experiments on the WordPress site. All privacy and data handling comply with WordPress.org Plugin Guidelines.

== Frequently Asked Questions ==

= What is Sigmize? =
Sigmize is an A/B testing, element testing, heatmap, and session replay plugin built for WordPress. It combines page testing, element-level testing, heatmaps, session replays, custom goals, and revenue tracking in one dashboard so you can see which variations actually increase sales.

= How is Sigmize different from Nelio A/B Testing or OptinMonster? =
Sigmize focuses on WordPress e-commerce stores and connects your A/B tests directly to real revenue from WooCommerce, SureCart, and EDD. You get A/B + element testing, heatmaps, session replays, and revenue tracking all in one plugin instead of stitching together multiple tools.

= Can I use Sigmize to test WooCommerce product pages? =
Yes. Test product images, pricing, descriptions, CTAs, and checkout flows. Track add-to-cart events, purchases, average order value, and cart abandonment per variation. See which changes actually increase WooCommerce revenue.

= Does Sigmize work with SureCart? =
Yes. SureCart stores can track purchases, revenue, and checkout completion per variation. Test pricing pages, product descriptions, and checkout flows to increase SureCart sales.

= Can I set custom goals like scroll-depth or time-on-page? =
Yes. You can configure custom goals to track how far users scroll, how long they stay on the page, form submissions (including SureForms and other custom forms), and other key actions like button or link clicks.

= Can I see revenue impact from A/B tests? =
Yes. Sigmize connects your tests directly to real purchases from WooCommerce, SureCart, and EDD so you see which variation actually increased revenue, not just clicks and page views.

= Does Sigmize work with Easy Digital Downloads? =
Yes. Track EDD purchases and revenue per variation. Test product pages and pricing to optimize for digital product conversions.

= Can I use Sigmize for lead generation or form testing? =
Yes. You can test pages and elements that contain forms, then set custom goals to track form submissions, signups, email captures, and other lead-generation events.

= Does Sigmize slow down my site? =
Sigmize uses lightweight frontend code, server-side caching, and intelligent traffic distribution to minimize overhead on your WordPress site.

= Is Sigmize GDPR compliant? =
Sigmize is designed to support GDPR and CCPA. You can use Sigmize's own CMP or integrate with third-party CMPs like CookieBot so tracking respects user consent.

= Can I test with my page builder? =
Yes. Sigmize works with Elementor, Divi, Beaver Builder, Gutenberg, GeneratePress, StudioPress, and custom WordPress themes. You can run tests on pages built with your existing builder.

= How can I report a security bug? =
We take plugin security extremely seriously. If you discover a security vulnerability, please report it in a safe and responsible manner.

You can report the issue through our [Bug Bounty Program](https://brainstormforce.com/bug-bounty-program/). We collaborate with Patchstack to provide opportunities for researchers to report vulnerabilities. The Patchstack team will help validate, triage, and handle any reported security issues.
